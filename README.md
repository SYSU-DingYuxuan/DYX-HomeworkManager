# DYX班级作业助手

《班级作业助手》项目开始于2022年10月。在2022-2024这两年中中，产品已经经历了2次大版本迭代、30余次版本更新，现最新稳定版为3.4.2版本。

作为高中生自学5年 Python ，在紧张的高中生活中诞生的成果，《班级作业助手》汇集了作者大量的实战经验，并且在实际投入使用中得到了检验。

由于 Tkinter 是个较为基础的轻量级的工具集，想要做出漂亮的视觉效果，是要比 Qt 等难上很多的。由于作者能力有限，本软件暂只支持 1920x1080 分辨率的屏幕。想要适配更多屏幕也不是不行，但很繁琐，繁忙的高中令作者没时间搞这个，就暂时搁置了，反正学校希沃就是这个分辨率。😝

此次开源，大家既可以互相交流学习技术，也可以共同开发，争取早日真的能在 heqj 落地实施。
